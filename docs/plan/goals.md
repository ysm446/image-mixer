# Image Mixer の目標

作成日時: 2026-08-05 22:27
更新日時: 2026-08-07 05:52

## プロジェクトの目的

Image Mixer は、複数の画像と編集指示をノードグラフ上で組み合わせ、ローカルの ComfyUI で画像を生成・再編集する Windows 向けデスクトップアプリです。

[ysm446/lm-graph](https://github.com/ysm446/lm-graph) の「素材と生成結果をノードとして残し、接続関係によって生成の流れを見えるようにする」操作感を画像編集へ適用します。ComfyUI 自体の複雑な内部グラフを利用者へそのまま見せるのではなく、画像合成に必要な概念だけをアプリ側のノードとして提供します。

## 想定する利用の流れ

1. プロジェクトを作成する。
2. テキストだけで画像を生成するか、1～3枚の入力画像を画像ノードとして読み込んで編集する。
3. 画像ノードを生成ノードへ接続し、編集指示、解像度、seed などを設定する。
4. 生成ノードを実行し、ComfyUI の進捗と結果をアプリ上で確認する。
5. 生成結果を次の生成ノードへ接続し、段階的に合成・修正する。
6. グラフ、設定、入力画像、生成履歴を保存し、後から再現または再編集する。

## 完成形

- React Flow ベースのキャンバスで、画像入力、画像生成、生成結果を型付きエッジで接続できる。
- キャンバスの右クリックメニューからノード種別を選び、クリック位置へ追加できる。
- 左ドラッグで複数ノードを範囲選択・一括移動でき、`F`で選択範囲、`A`で全体を表示できる。
- 選択したノードをコピー＆ペーストでき、選択ノード同士を結ぶエッジもまとめて複製できる。
- 生成ノード単位で prompt、出力サイズ、seed、steps、CFG、sampler、scheduler、denoise、生成枚数を設定できる。
- `workflows/` の API 形式ワークフローをテンプレートとして読み込み、アプリの設定値を安全に差し替えて ComfyUI へ送信できる。
- `Qwen-Rapid-AIO-NSFW-v23.safetensors` と `TextEncodeQwenImageEditPlus` を使い、最大3枚の参照画像から画像編集を実行できる。
- 実行待ち、実行中、完了、失敗、キャンセルをノード上で確認できる。
- 生成中はリアルタイムの経過時間を表示し、結果保存または失敗後も確定した生成時間を生成ノードで確認できる。
- 生成結果をクリップボードへ画像としてコピーし、任意の保存先へ書き出せる。
- 生成結果をクリックして画面内へ拡大表示し、背景クリックでノード表示へ戻れる。
- 生成結果をローカルへ保存し、使用した入力、prompt、パラメータ、ワークフローバージョンを追跡できる。
- プロジェクトを保存してアプリを終了し、同じグラフと生成履歴から作業を再開できる。
- Python と ComfyUI はリポジトリ内の仮想環境から起動し、システム Python を汚さない。
- 画面下部のステータスバーでComfyUI状態、現在のセッション、CPU・RAM・GPU・VRAM使用量を確認できる。

## MVP の範囲

- Windows ローカル環境での単一ユーザー利用。
- 1つの ComfyUI サーバーと1つの固定ワークフローテンプレート。
- 画像入力ノード、モデル非依存の`Image Generate`ノード、生成結果ノード。現在のMVPでは実行モデルにQwenを使用する。
- 生成ノードにつき最大3枚の画像入力。
- Promptノードを生成ノードへ接続し、Promptノードの本文をComfyUIへ送信する。
- 生成ノードの最新結果を `IMAGE` 出力として次の生成ノードへ接続できる。
- 逐次実行を基本とする生成キュー。
- 選択フォルダ直下の画像を1枚ずつ既存の生成キューで処理し、新しい出力フォルダへまとめて保存するバッチ生成ノード。
- プロジェクト、グラフ、画像アセット、生成メタデータのローカル保存。
- 任意のルートフォルダを選択し、その配下で複数セッションを個別に作成・名前変更・複製・切り替え・削除できる。
- Imageノードへ画像ファイルをドロップして読み込める。
- Imageノードは画像の縦横比に合わせて表示サイズを変え、元画像の解像度を表示する。
- 生成ノードはImage 1へ接続した画像の解像度をwidth / heightへ反映できる。
- 生成ノードは設定解像度と生成結果の縦横比に合わせて表示サイズを変える。
- ComfyUI の起動・停止、接続状態、実行進捗、エラーの表示。

## 重視する価値

- ローカル完結: 入力画像、モデル、生成結果を外部サービスへ送信しない。
- 再現性: seed と実行パラメータだけでなく、使用ワークフローとモデルも記録する。
- 見通しのよさ: どの画像を使い、どの指示で、どの結果を作ったかを接続関係から追える。
- 反復しやすさ: 結果を次の入力としてつなぎ、非破壊で試行を重ねられる。
- 破綻しにくさ: 型付き接続、サイクル防止、実行前検証、明示的な保存で事故を減らす。
- 実装の分離: アプリの編集グラフと ComfyUI の実行グラフを分け、ワークフロー更新の影響を局所化する。

## 非目標

- ComfyUI の全ノードを再実装する汎用フロントエンド。
- クラウド推論サービスや複数ユーザー同期。
- 動画・音声生成。将来拡張は妨げないが、MVP には含めない。
- 複数 GPU へのジョブ分散や同時並列レンダリング。
- モデル本体やユーザー生成画像のバージョン管理への追加。
