# UI スタイルガイド

作成日時: 2026-08-11 18:22
更新日時: 2026-08-11 18:22

このドキュメントは Image Mixer の UI(色、タイポグラフィ、余白、部品、モーション、文言)の統一ルールです。
UI に関わる変更を行うときは、実装前に本ガイドを読み、**既存の値を再利用する**ことを最優先にします。

対象は `src/renderer/` 配下の画面全体(上部バー、左サイドバー、キャンバス、ノード、ダイアログ、ステータスバー)です。

---

## 1. アートスタイルの原則

Image Mixer は「暗い作業台の上に、光る素材と接続関係を置く」ノードエディタです。次の性格を全画面で守ります。

1. **暗い背景・低彩度の面・高彩度のアクセント**
   面(パネル、カード、入力欄)は青みがかったダークグレーで、彩度を持つのは「型」「状態」「主要操作」だけです。
2. **色は意味を持つ**
   紫 = TEXT、青 = IMAGE、オレンジ = 生成、緑 = 準備完了、黄 = 進行中/注意、赤 = 失敗/破壊的操作。
   装飾目的で意味と異なる色を使いません。
3. **線画アイコンのみ**
   絵文字やフォント文字をアイコン代わりに使いません。すべて `stroke` ベースの SVG です。
4. **輪郭 + 影で階層を作る**
   面の重なりは「1px の境界線」と「黒い落ち影」で表します。明度差だけに頼りません。奥から手前へ、
   キャンバス → パネル → カード → ポップオーバー → ダイアログ の順に影を強くします。
5. **情報密度は高く、文字は小さく、余白は詰めすぎない**
   本文 11〜12px、補助 9〜10px が基準です。小さい文字ほど字間を広げ、うるさくならないよう色を落とします。
6. **動きは短く控えめ**
   ホバーなどの状態変化は 0.14〜0.18s。派手なイージングやバウンスは使いません。
7. **ダークテーマ固定**
   `color-scheme: dark` 前提です。ライトテーマは現時点で非対応であり、対応する場合は本ガイドの改訂が先です。

### 2.2 テキスト

| --- | --- | --- |
| 既定文字色 | `#e9eef7` | `:root` |
| 見出し・強調 | `#f2f5f9`(ノードタイトル) / `#edf3fb`(ダイアログ h2) | 15〜18px |
| 本文 | `#dfe7f2`(テキストエリア) / `#e6edf7`(入力値) | 11〜12px |
| 二次テキスト | `#bdc9d8` / `#c7d2e0` / `#aab6c5` | メニュー項目、選択肢 |
| 補助テキスト | `#8490a0` / `#718095` / `#77869a` | ラベル、キャプション |
| 抑制テキスト | `#667286` / `#69768a` / `#59667a` | 説明文、無効寄りの情報 |

コントラスト確保のため、`#66`〜`#69` 台の色は 9〜10px の補助情報にのみ使い、操作の可否を伝える文字には使いません。

### 2.3 型と機能のアクセント

接続型とノード種別の色は **意味に固定** されています。ここを崩さないでください。

| 意味 | 主色 | 明色(文字/ラベル) | 暗色(枠/面) | グロー |
| --- | --- | --- | --- | --- |
| TEXT(Text / Image Describe / Text Transform) | `#a878ff` | `#c8aaff` | `#4b3d61` 枠 / `#17111f` 面 | `#a878ff38` |
| IMAGE(Image ノード、画像ピン) | `#45b8ff` | `#73cceb` / `#67c6ff` | `#3a4b60` 枠 | `#45b8ff38` |
| 生成(Image Generate / Batch Image Generate) | `#ff9a52` | `#ffae72` / `#e4a77e` | `#5b3a27` 枠 / `#1d140f` 面 | `#ff9a5238` |
| UI 一般のフォーカス/選択 | `#58b7ff` / `#55b8f3` | `#7fc4f2` / `#9fd3ff` | `#3a6d96` 枠 | `#55b8f31c` |

- ノードカードは `--node-accent`(枠色)と `--node-accent-glow`(選択時の光)の 2 変数で色を切り替えます。**新しいノード種別を追加するときは、この 2 変数だけを定義**し、個別に `border-color` を書かないでください。
- ハンドル(ピン)とエッジの色は接続型に従います。TEXT 系は紫、IMAGE 系は青。ノードの見た目の色ではなく **型** に合わせます。
- 右クリックメニューの `.node-type-dot` もノード種別の主色と一致させます。

### 2.4 状態色

| 状態 | 主色 | 面/枠 | 使用箇所 |
| --- | --- | --- | --- |
| 準備完了 / 成功 | `#53d18a`(文字 `#7fe1aa`, 成功件数 `#67d6a1`) | `#53d18a18`〜`#53d18a20` | LLM ロード済み、スクリーンショット通知 |
| 接続済み(ComfyUI) | `#58b7ff` | `#14283a` | 上部バーの状態ドット |
| 進行中 / 注意 | `#f6bd60`(枠 `#8a6a34`, 面 `#282114`) | — | ロード中、再ロード待ち |
| 資源使用の警告 | `#f59e42` | — | リソースバー warning |
| 失敗 / 危険 | `#ff6b6b` / `#ff9aa1`(文字), `#ef5d68`(バー), `#e86c72`(欠損) | 枠 `#6b3437`〜`#713a40`, 面 `#2b1519`〜`#2c171a` | エラーバナー、削除メニュー、Cancel |
| 待機(queued) | `#a9c9e9` | 枠 `#49627f`, 面 `#17212d` | `.node-queued` |
| キャンセル済み | `#d8b98e` | 枠 `#5b4c3a`, 面 `#251f17` | `.node-canceled` |
| 未接続 / 不明 | `#697384` | `#69738418` | 状態ドットの既定 |

**状態ドットの作り方**は共通です: 直径 8〜9px の円 + `box-shadow: 0 0 0 4px <主色>18〜20`(薄いハロー)。進行中はさらに `animation: pulse 1.2s infinite`。

### 2.5 色を追加したくなったら

1. まず 2.1〜2.4 に該当する役割があるかを探し、あればその値を使う。
2. 既存色の明暗違いが必要な場合は、`filter: brightness()` / `opacity` / アルファ付き hex(`#45b8ff1a` 形式)で派生させる。
3. どうしても新色が必要なら、本ガイドへ役割名付きで追記してから実装する。**ガイドに無い色をコードにだけ足さない。**

## 3. タイポグラフィ

### 3.1 フォント

- 標準: `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- 等幅: `ui-monospace, SFMono-Regular, Consolas, 'Liberation Mono', monospace`
  → モデル名、ファイル名など「識別子」にだけ使う。
- `font-synthesis: none`。太さは実在するウェイトで表現する。
- `button, input, textarea` は `font: inherit`(既に `index.css` で指定済み)。

### 3.2 サイズと役割

| px | 役割 | ウェイト |
| --- | --- | --- |
| 18 | ダイアログ見出し(`h2`) | 標準 |
| 15 | ノードタイトル | 700 |
| 13 | 上部バーのモデル名(等幅) | 600 |
| 12 | ノード本文テキストエリア、選択肢の主要行 | 標準 |
| 11 | 一覧項目、メニュー項目、入力値、小ボタン | 標準〜650 |
| 10 | ステータスバー、ダイアログのラベル、小さな注記 | 標準〜700 |
| 9 | メタ情報、ピンラベル、キャプション、エラー本文 | 標準〜800 |
| 8 | マイクロラベル(`OUTPUT` などの全大文字) | 800〜850 |

新しい要素にはこの中から選びます。中間サイズ(14px, 16px など)を独自に持ち込まないでください。

### 3.3 マイクロラベル(全大文字)

`.node-kicker`, `.sidebar-label`, `.node-context-title`, `.llm-settings-section-title`, `.output-label` などの
「小さな全大文字ラベル」は次のセットで統一します。

- サイズ 8〜10px / ウェイト 800〜850
- `letter-spacing: .1em`〜`.17em`(小さいほど広く)
- 色は抑制テキスト(`#647286` 前後)。ただし型を示すラベルは型の明色を使う。

### 3.4 数値の表示

時間、解像度、使用率、サイズなど**変動する数値には必ず `font-variant-numeric: tabular-nums`** を付け、桁の揺れを防ぎます。

### 3.5 行間と省略

- 説明文・エラー文は `line-height: 1.4`〜`1.5`、テキストエリアは `1.5`〜`1.55`。
- 幅が可変の 1 行テキストは `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;` の 3 点セットを付け、
  親に `min-width: 0` を入れて grid/flex での溢れを防ぐ。

## 4. 余白・寸法・角丸・影

### 4.1 レイアウトの固定値

| 対象 | 値 |
| --- | --- |
| 上部バー高さ | 44px(内部コントロールは 30px) |
| ステータスバー高さ | 34px |
| 左サイドバー幅 | 既定 270px(ドラッグでリサイズ、ダブルクリックで 270px へ戻す) |
| サイドバーのリサイザ | 当たり判定 7px / 表示 1px、ホバー時 3px `#55b8f3` |
| ダイアログ幅 | `min(680px, calc(100vw - 56px))`(モデル選択は 620px) |
| 拡大プレビュー枠 | 768 × 768px、`max-*: calc(100v* - 64px)` |

### 4.2 余白スケール

実装では 4〜22px の範囲を使います。新規追加は次から選び、独自の値を増やさないでください。

`4 / 6 / 8 / 10 / 12 / 16 / 22`

既存コードにある 5, 7, 9, 11, 13, 15, 18 は光学的な微調整として現存します。**既存部品を編集するときは周囲の値に合わせ**、新規部品では上の基準値を使います。

代表的な適用:

- ノードカード内側: `padding: 15px`、要素間 `margin-top: 8〜13px`、設定グリッドの前は `22px`
- ダイアログ内側: `padding: 18〜20px`、セクション区切り `padding: 15〜16px 0`
- サイドバーのセクション: `padding: 15〜17px 10〜13px`
- 一覧項目: `padding: 8〜10px`、項目間 `margin-bottom: 4px`

### 4.3 コントロールの寸法

| 部品 | サイズ |
| --- | --- |
| 上部バーのボタン・状態バー | 高さ 30px |
| アイコンボタン(上部バー、画像差し替え) | 30 × 30px |
| アイコンボタン(サイドバー追加) | 27 × 27px |
| アイコンボタン(三点メニュー、タイトル編集) | 25 × 25px / 22 × 22px |
| 結果枠のアクションボタン | 29 × 29px |
| ノード内のテキスト入力 | `padding: 10px`、最小高さ 92〜180px |
| ノード内の数値入力 | `padding: 7px 8px` |
| ダイアログ入力 | `padding: 9px 10px` |
| チェックボックス | 16 × 16px(カスタム) |

### 4.4 角丸

| 値 | 用途 |
| --- | --- |
| 5〜6px | メニュー項目、極小ボタン |
| 7px | 小さな入力欄、小アイコンボタン、バナー |
| 8px | 一覧項目、ポップオーバー、ダイアログ内入力 |
| 9px | 標準コントロール、主要ボタン、ノード内テキストエリア |
| 10〜11px | 画像枠、選択肢カード、トースト |
| 13〜14px | ノードカード、ダイアログ、ミニマップ |

**入れ子のときは外側より内側を 2〜5px 小さく**します(例: ノード 14px の中の入力 9px)。

### 4.5 影

| 階層 | 値 |
| --- | --- |
| ノードカード | `0 12px 32px #0008` |
| 選択中ノード | `0 0 0 2px var(--node-accent), 0 0 24px var(--node-accent-glow), 0 16px 38px #0009` |
| ポップオーバー/メニュー | `0 10px 28px #000a` 〜 `0 14px 36px #000b` |
| トースト/ミニマップ | `0 16px 42px #000b` |
| ダイアログ | `0 24px 80px #000c` 〜 `#000d` |
| フォーカスリング | `0 0 0 2〜3px <アクセント>1c〜38`(色の付いた薄いリング) |

選択・フォーカスは **枠線色の変更 + リング** で表し、サイズを変えて位置をずらすことはしません。

## 5. モーション

| 用途 | 値 |
| --- | --- |
| ホバー・状態変化 | `.14s`〜`.18s ease`(対象プロパティを列挙し、`all` は使わない) |
| 進捗バーの伸長 | `.2s`〜`.25s ease` |
| リソース使用率 | `width .5s ease-out, background-color .2s ease` |
| 回転(スピナー、切替中アイコン) | `spin .8s linear infinite` |
| 点滅(進行中ドット) | `pulse 1.2s infinite`(`50% { opacity: .35 }`) |
| ロード中の帯 | `llm-loading-sweep 1.4s linear infinite` |
| トースト出現 | `.2s ease-out`(`translateY(12px) scale(.98)` から) |

既存キーフレーム(`spin`, `pulse`, `llm-loading-sweep`, `screenshot-toast-in`)を再利用し、同じ意味の新規アニメーションを追加しないでください。

## 6. アイコン

- 形式は **インライン SVG のみ**。絵文字・フォント文字・画像アイコンは使いません。
- 共通属性: `fill: none; stroke: currentColor; stroke-linecap: round; stroke-linejoin: round;`
- `stroke-width`: 標準 `1.7` / 小さい実体アイコン `1.8` / 繊細な装飾(歯車など) `1.4`
- サイズ: 上部バー 17〜18px、ノード内 14〜16px、サイドバー 15〜17px
- 色は `currentColor` に任せ、親要素の文字色で制御します。アイコン単体に固定色を付けない。
- 塗りが必要な場合(三点メニューなど)は `fill: currentColor; stroke: none;` を明示します。
- ボタン内のアイコンは `display: grid; place-items: center;` で中央に置き、行揃えを目分量で調整しない。

## 7. 部品カタログ

新しい UI を作るときは、まずここに一致する部品があるかを探します。

### 7.1 ボタン

| 種別 | 見た目 | 例 |
| --- | --- | --- |
| 主要アクション(生成) | 枠 `#bd7140` + `linear-gradient(#a75f34, #75401f)` | `.generate-button` |
| 主要アクション(LLM) | 枠 `#865cc7` + `linear-gradient(#7650af, #4f3578)`、文字 `#f8efff` | `.describe-button`, `.transform-button` |
| 破壊/中断 | 枠 `#a94b52` + `linear-gradient(#7f343a, #542227)`、文字 `#ffe5e7` | `.cancel-generation-button` |
| 二次アクション | 枠 `#384657`、面 `#171f2a`、文字 `#aab8c9`、10px | ダイアログのボタン |
| 既定(primary 指定) | 枠 `#39739a`、面 `#245f86`、文字 `#eff9ff` | ダイアログの保存 |
| ゴースト(アイコンのみ) | 枠なし・背景透明、ホバーで文字色を上げる | `.llm-settings-button` |

共通ルール:

- 幅いっぱいの主要ボタンは `width: 100%; margin-top: 11px; padding: 10px; border-radius: 9px; font-weight: 750`。
- ホバーは `filter: brightness(1.13〜1.14)`(グラデーション系)または枠色と面色を 1 段明るく(フラット系)。
- 無効時は `cursor: not-allowed; opacity: .48〜.5; filter: grayscale(.55〜.6)`。
  **無効なボタンは消さずに残し、理由を `title` に書く**(例: `Local LLMをロードしてください`)。
- 実行中は同じ位置のボタンを Cancel 系へ差し替え、ボタンを増やさない。

### 7.2 入力欄

- ノード内: 面 `#0d1219`、枠 `#303a48`、`border-radius: 7〜9px`、`outline: none`。
- フォーカス時の枠色は **その部品の文脈色**: テキスト系 `#8e65d1`、生成設定 `#c17641`、設定ダイアログ `#5b9fc8`。
- プレースホルダは `#667286` 前後 + `opacity: .82`。既定値がある場合は**実際に送信される既定値の全文をプレースホルダで見せる**(Image Describe の System Prompt が前例)。
- 読み取り専用の出力欄は文字色を通常と同じ `#dfe7f2` に保ち、「無効」に見せない。
- 無効時は `opacity: .6`。

### 7.3 チェックボックス

`.match-size-toggle` がカスタム実装の基準です。ネイティブ描画に戻さないでください。

- 16 × 16px、`appearance: none`、枠 `#46566a`、面 `#0d1219`、`border-radius: 5px`
- チェック時: 枠・面ともに `#58b7ff`、内側にチェック記号(`#06131c` の擬似要素)
- `:focus-visible` で `box-shadow: 0 0 0 3px #45b8ff38`
- ラベル全体がクリック領域で、ホバー時に文字色を上げる
- 設定ダイアログ内の簡易チェックは `accent-color: #55aede` を使用

### 7.4 メニュー / ポップオーバー

- 面 `#171e28`(または `#151c25`)、枠 `#394657`、`border-radius: 8〜9px`、`padding: 4〜5px`
- 項目は `border-radius: 5〜6px; padding: 7〜9px; font-size: 11px`、ホバー `#253141`
- 破壊的項目は文字 `#ff9aa1`、ホバー面 `#3a2025`
- 区切りは 1px の `#2a3442`
- **スクロール領域に切られる可能性がある場合は `position: fixed` + 画面座標**で配置する(セッション三点メニューが前例)
- `z-index`: ポップオーバー 80 / 拡大プレビュー 120 / 設定ダイアログ 130 / モデル選択 135 / トースト 150

### 7.5 ダイアログ

- バックドロップ: `#030508b8`〜`#030508df` + `backdrop-filter: blur(4〜5px)`、`display: grid; place-items: center; padding: 28px`
- 本体: 面 `#10161f`、枠 `#394657`〜`#414e60`、`border-radius: 14px`、`padding: 18〜20px`
- ヘッダは「小さな全大文字の目印(`#64bce6`, 9px, 850) + `h2` 18px + 補足 10px」の 3 段構成
- フッタは左に状況テキスト(9px `#718095`)、右にボタン群
- 閉じるボタンは 30 × 30px の枠付き(`.llm-dialog-close`)
- Escape と背景クリックで閉じられること

### 7.6 バナー(ノード内の状態表示)

`margin-top: 9px; border-radius: 7px; padding: 7px; font-size: 9px; line-height: 1.4` を共通とし、色だけを状態で変えます。
エラー = 赤系、待機 = 青系、キャンセル = 黄土系(2.4 の表を参照)。サイドバーのエラーも同じ考え方(`.sidebar-error`)。

### 7.7 進捗表示

- トラック: 高さ 3〜5px、`border-radius: 3px`/`99px`、面 `#232d3a` または `#ffffff12`〜`#ffffff14`
- フィル: 文脈色のグラデーション(汎用 `#3f8fd0 → #58b7ff`、バッチ `#a75f34 → #ff9a52`)
- 数値は隣に `tabular-nums` で表示し、幅を固定して揺れを止める
- 不定の待ち時間はスピナー(`.spinner`: 24px、枠 `#344052`、上端 `#ff9a52`)

### 7.8 トースト

右下(`right: 18px; bottom: 50px`)に 1 枚だけ表示します。幅 `min(370px, calc(100vw - 36px))`、
左に丸アイコン、中央に見出し + 補足、右端に閉じるボタン。本体クリックで主要動作(保存先を開く等)を実行します。
複数を積み上げる設計にはしません。

### 7.9 一覧項目(セッション行など)

- 既定は枠なし、ホバーで面 `#151c26`、選択中は枠 `#3c4d62` + `linear-gradient(90deg, #1b2a3a, #17202b)`
- 左端に 6px のドット(選択中は `#55b8f3` + ハロー)で状態を示す
- 主行 11px/650、副行 9px `#606e81`
- 行内の操作ボタンはホバー時に出現させ、レイアウトを動かさない(常時同じ幅を確保する)

### 7.10 スクロールバー

細く、装飾を持たせません。

```css
scrollbar-color: #4e5968 transparent; scrollbar-width: thin; scrollbar-gutter: stable;
/* WebKit: width 8px、thumb #4e5968 + border 2px transparent + background-clip: padding-box、button は非表示 */
```

## 8. キャンバスとノード

### 8.1 ノードカード

- 基準幅 280px。種別ごと: Text 320 / Image Describe 360 / Text Transform 380 / Batch Image Generate 390。
- Image と Image Generate は **画像の縦横比に合わせて可変**(360 × 360px 基準で算出した表示サイズ + 30px の左右余白)。
  この計算は両ノードで必ず共有し、同じ解像度の画像が別サイズで表示されないようにします。
- `padding: 15px`、`border-radius: 14px`、枠は `var(--node-accent)`。
- 構成順: キッカー(全大文字) → タイトル行 → 主要コンテンツ → 設定 → 状態バナー → 主要ボタン。
- タイトルは通常表示専用で、横の鉛筆アイコンから入力へ切り替える。

### 8.2 ハンドルとピンラベル

- ハンドルは 12 × 12px、`border: 2px solid #11161e`、色は接続型(紫/青)。
- 入力ハンドルは `left: -7px`、出力は `right: -7px`。
- 入力ピンの縦位置は 58 / 84 / 110 / 136px(**26px 間隔**)。ラベルは各ハンドルより 5px 上。
- ラベルは**ノードの外側**に置く(`right: calc(100% + 18px)` / `left: calc(100% + 18px)`)。ノード内へ重ねない。
- ラベル文字は 8〜9px、型色。`pointer-events: none` を必ず付ける。

### 8.3 キャンバス操作の見た目

- 範囲選択の矩形: 枠 `#66bfff`、面 `#45b8ff1a`
- 選択エッジ: `stroke-width: 3` + `drop-shadow(0 0 3px #ffffff66)`
- ミニマップ: 230 × 150px、`border-radius: 13px`、`opacity: .92`(ホバーで 1)、表示は設定で切り替え可能
- 背景ドットの表示も設定で切り替え可能。既定の見え方を変える場合は設定項目とセットで検討する。

## 9. 文言ルール

- **操作名・パラメータ名・型名は英語**: `Generate`, `Describe`, `Transform`, `Cancel`, `Instruction`, `Context length`, `TEXT`, `IMAGE`。
  ComfyUI や LLM の用語はそのままの綴りを使う。
- **説明文・見出し・エラー・ツールチップは日本語**: 「モデルを選択」「画像を接続してください」「Enterで確定・Escで取消」。
- 全大文字は 8〜10px のマイクロラベルに限る。ボタン名を全大文字にしない。
- 句点は説明文のみ。ラベル・ボタン・短い注記には付けない。
- 単位は数値と半角スペースなしで連結(`1024px`, `12.3s`)。解像度は `1024 × 1024`(全角 × の前後に半角スペース)。
- 無効理由・所要時間・保存先など、**利用者が次に何をすべきかが分かる情報**を優先して置く。

## 10. アクセシビリティと操作性

- アイコンのみのボタンには必ず `aria-label`、補足が必要な操作には `title` を付ける。
- トグル状態は `aria-pressed`、展開状態は `aria-expanded` で表す(既存: サイドバー開閉ボタン、三点メニュー)。
- ダイアログは `aria-labelledby` で見出しと結び、Escape で閉じる。
- キーボードフォーカスは `:focus-visible` で必ず見えるようにする(色付きリング)。`outline: none` を書いたら代替を必ず用意する。
- キャンバス上の入力要素には `nodrag` クラスを付け、ドラッグ操作と競合させない。
- 破壊的操作(削除など)は赤系で示し、他の項目と隣接させすぎない。

## 11. CSS 実装ルール

1. スタイルは `src/renderer/src/index.css` に集約する。CSS-in-JS やコンポーネント別ファイルを新設しない。
2. クラス名は **kebab-case**、機能プレフィックス付き(`node-`, `llm-`, `session-`, `batch-`, `image-`, `result-`)。
   状態は独立クラス(`.selected`, `.active`, `.status-ready`, `.is-dragging`, `.has-image`)で表し、要素セレクタへ状態を埋め込まない。
3. 宣言の並び順は既存行の順序に合わせる(position → display/レイアウト → ボックス → 見た目 → 文字 → その他)。
   既存行を編集するときは並びを壊さない。
4. インライン `style` は **実行時に決まる数値のみ**(算出した幅・高さ、進捗の `width`、メニューの座標)。
   色、フォント、角丸、余白をインラインで書かない。
5. `!important` は React Flow が付与するスタイルを上書きする場合に限る(`.handle`, `.pin-*`, `.output-handle` など)。新規で安易に使わない。
6. `transition` は対象プロパティを列挙する。`all` は使わない。
7. 半透明はアルファ付き hex(`#45b8ff1a`)で表し、`rgba()` との混在を増やさない(既存の `.topbar` を除く)。
8. メディアクエリは幅の破綻を防ぐ目的でのみ使う(現状 `max-width: 1400px` の 1 箇所)。レイアウトの作り分けを増やさない。

## 12. UI 変更時のチェックリスト

UI に触れる変更を終えたら、次を自己確認します。

- [ ] 追加した色はすべて本ガイドの表にあるか(無ければガイドを先に更新したか)
- [ ] 接続型・ノード種別の色(紫 / 青 / オレンジ)を崩していないか
- [ ] フォントサイズは 3.2 の表の値か、余白・角丸は 4 章の値か
- [ ] 同じ役割の既存部品(ボタン、入力、メニュー、バナー)を再利用したか
- [ ] アイコンは線画 SVG で、`stroke-width` と `currentColor` の規約に従っているか
- [ ] ホバー・フォーカス・無効・実行中・エラーの 5 状態を用意したか
- [ ] `aria-label` / `title` / キーボードフォーカスを確認したか
- [ ] 数値表示に `tabular-nums`、可変テキストに省略 3 点セットを付けたか
- [ ] 新しい CSS が `index.css` にあり、命名規約と並び順に従っているか
- [ ] `npm run build` が通るか
